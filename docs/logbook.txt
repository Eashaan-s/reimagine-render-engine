WEEK 9 - Inference worker attached (100% generate path)
Date: _______________

Objective. Turn the mapped job from weeks 4-8 into a live image-edit run: the GPU worker must return a PNG without changing the frozen graph.

Work done. Wired the Generate path from the renderer through preload and main into an inference client. WEEK 10 - Backend selection, errors, and resolution policy
Date: _______________

Objective. Make inference reliable enough for a demo: choose hosted versus local worker, show honest errors, and document the working canvas size.

Work done. Implemented backend resolution (hosted GPU when credentials exist, otherwise local ComfyUI, unless RENDER_BACKEND is forced). Added connection checks and optional local engine start. Mapped common worker failures (missing drawing, missing credentials, unreachable engine, payment or paused endpoint) to status-bar messages. Confirmed the frozen graph uses ImageScaleToTotalPixels at three megapixels with Lanczos before VAE encode; Output reports the returned PNG width and height. Stated clearly that this is a 2K-class budget, not an 8K pixel claim.

Outcome. Generate either returns a PNG or a readable error. Resolution is an implementation policy, not a marketing number.

Next week. Ground the product in published I2I and diffusion papers so the report can cite methods without claiming we trained them.
